현열(顯熱)이란?

쉽게 말하면, 물질의 상태는 변하지 않고 온도만 변할 때 출입하는 열량 입니다.
여기서 상태가 변하지 않는다는 것은 고체·액체·기체가 그대로라는 뜻입니다.

1. 가장 쉬운 예
물을 20℃에서 30℃까지 가열
처음: 물
나중: 물
액체 상태 그대로
온도만 10℃ 상승

이때 물에 가해준 열이 현열입니다.
현열 계산에는 바로 우리가 앞에서 공부한 공식이 사용됩니다.

2. 왜 '현열'이라고 부르나요?

한자로 보면:
현(顯) = 나타날 현
열(熱) = 열

즉, 온도계에 온도 변화가 나타나는 열 이라고 생각하면 이해하기 쉽습니다.

열을 가했더니 온도계가:
20℃
25℃
30℃

이렇게 변합니다. 그래서 눈에 보이는 온도 변화가 있는 열 → 현열입니다.


3. 현열의 반대는 잠열입니다. Q=mL(질량*고유쟘열)

4. 현열의 예
① 물을 가열할 때
20℃ 물 → 50℃ 물
온도가 올라가므로 현열입니다.

② 물을 냉각할 때
30℃ 물 → 10℃ 물
온도가 내려가므로 현열입니다. 냉각할 때도 현열입니다.
즉, 온도가 올라가든 내려가든 상태 변화가 없이 온도가 변하면 현열입니다.

③ 공기를 냉각할 때
30℃ 공기 → 20℃ 공기
공기의 온도가 낮아졌습니다.
이때 제거된 열 중에서 온도를 낮춘 부분은 현열입니다.
다만 공조에서는 냉각하면서 습기가 물로 변하면 그 부분은 잠열입니다.


5. 현열과 잠열이 함께 발생하는 경우

예를 들어 20℃의 물을 계속 가열한다고 생각해보겠습니다.
① 20℃ → 100℃
온도만 올라갑니다. → 현열

② 100℃에서 물 → 수증기
온도는 그대로 100℃인데 상태가 변합니다. → 잠열

③ 수증기를 더 가열
100℃ → 120℃
온도가 다시 변합니다. → 현열

한 줄로 정리하면 온도가 변하면 현열, 상태가 변하면 잠열입니다.


6. 기사 실기에서 현열을 계산하는 방법

예를 들어:
20℃ 물 1,000kg을 50℃까지 가열하는 데 필요한 열량은?

질량 = 1,000kg
물의 비열 = 1 kcal/kg·℃
온도차 = 30℃

따라서 30,000 kcal의 현열이 필요합니다.


오늘 꼭 기억할 문장
현열 - 상태 변화 없이 온도 변화만 일으키는 열
잠열 - 온도 변화 없이 상태 변화를 일으키는 열

그리고 문제에서:

온도가 변한다 → Q=mcΔt
상태가 변한다 → Q=mL

이렇게 판단하면 됩니다.
