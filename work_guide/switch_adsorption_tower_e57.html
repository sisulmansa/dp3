🔄 흡착탑 교번-E57

가이드 목록
📅 작업 개요 및 교번 정보
  • 작업 주기: 매달 말일 당직자가 수행
  • 교번 정보: 이번 달에 교번(교체 가동)할 흡착탑 번호 등 상세 정보는 사무실 벽면에 부착되어 있습니다. 반드시 확인 후 조작하세요.
🟢 1. 기존 흡착탑 정지
  1. 화면에서 정지시킬 흡착탑을 클릭합니다.
  2. 팝업 메뉴에서 Stop 버튼을 클릭한 후,
    X 버튼을 눌러 창을 닫습니다.
  3. 모니터링 화면에서 숫자가 점차 줄어들어 2 이하가 되면, 색상이 초록색으로 변하며 완전히 멈추는지 확인합니다.
🔴 2. 교번할 새 흡착탑 가동
  1. 화면에서 새로 가동할 흡착탑을 클릭합니다.
  2. 팝업 메뉴에서 Reset 버튼을 2번 클릭합니다.
  3. Start 버튼을 클릭한 후, X 버튼을 눌러 창을 닫습니다.
  4. [Hz 값 변화 확인]
    새로 가동한 흡착탑의 Hz 값은 점차 커지고, 이미 가동 중이던(유지되는) 흡착탑의 Hz 값은 작아지면서 최종적으로 두 값이 비슷해지는지(균형을 맞추는지) 확인합니다.
  5. 가동을 시작한 흡착탑의 색상이 붉은색으로 변하여 정상 가동 중임을 알리는지 최종 확인합니다.
