가이드 목록
✅ Ready (준비 및 참고사항)
  • 준비물: 필터교체 자석스티커, 일자 시계드라이버, 윈도우 닦을 걸레/휴지
  • E8-B1 게이트에서 하이엠 외부 업체 인솔
  • LG 또는 SNI 담당자에게서 LOTO 대장 수령
  • 사전 요청: E8-8F 공조실1 BPP (나라컨트롤 요청), 공조실2 LS-05 (CA 중앙관제 02-6987-1112 OFF 요청)
  • 작업 중 확인: 윈도우를 깨끗이 닦고, 벨트 상태(장력, 세로크랙, 뜯김) 점검 및 필요시 사진 촬영/보고
📍 E8-B1-실험동물공조실

* 나라컨트롤 담당자에게 공조기 작업 순서 공지
* 예비 004는 작업 제외, 001~003 순서로 작업

AHU-001 작업 순서
  1. 004 예비 공조기 ON & 001 공조기 OFF
  2. 제어반패널 REM → PNL 전환
  3. LOTO 대장 "부착일시" 작성
  4. 하이엠 작업자 작업 시작 지시
  5. 1,2층 여재(부직포 필터) 작업
  6. 작업 완료 후 차압계 영점 조정
  7. 제어반패널 PNL → REM 전환
  8. LOTO 대장 "제거일시" 작성
  9. 나라컨트롤 담당자에게 001 작업 완료 통보
  10. 나라컨트롤 담당자가 004 공조기를 OFF 하고 001 공조기를 재가동
📍 E8-B2-기계실

* 직접 AHU-LS-1~3 전원 제어
* 실험실 공조기가 아니므로 전원을 임의로 껐다 켜도 무방함

  1. LOTO 대장 "부착일시" 작성
  2. 전원 OFF (공조기 옆 제어 LCD 패널 이용)
  3. 공조기 양쪽 컨트롤러 레버 "자동 → 수동" 전환
  4. 하이엠 작업자 작업 시작 지시
  5. 여재(부직포 필터) 작업
  6. 작업 완료 후 차압계 영점 조정
  7. 공조기 재가동
  8. 컨트롤러 레버 "수동 → 자동" 전환
  9. LOTO 대장 "제거일시" 작성
📍 E8-8F 공조실
⏱ BPP와 LS-05는 반드시 13:00~14:00 사이에 작업을 맞춰야 하므로 먼저 작업을 시작합니다.
공조실1: BPP 작업

* 나라컨트롤 담당자가 공조기 OFF

공조실2: LS-05 작업 순서
  1. CA 중앙관제 (02-6987-1112) 전화
  2. 공조기 OFF 요청 → 꺼짐 확인
  3. 제어반패널 REM → PNL 전환
  4. LOTO 대장 "부착일시" 작성
  5. 하이엠 작업자 작업 시작 지시
  6. 1,2층 여재(부직포 필터) 작업
  7. 작업 완료 후 차압계 영점 조정
  8. 제어반패널 PNL → REM 전환
  9. LOTO 대장 "제거일시" 작성
  10. CA 중앙관제 (02-6987-1112) 전화
  11. 작업 완료 통보 및 공조기 재가동 요청
  12. 모츄럴 댐퍼를 가리키는 램프 점등 확인
