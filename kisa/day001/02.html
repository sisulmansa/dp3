1 현열의 정의와 어원

현열(顯熱)을 쉽게 말하면, 물질의 상태(고체·액체·기체)는 변하지 않고 온도만 변할 때 출입하는 열량입니다.

가장 쉬운 예

물을 20℃에서 30℃까지 가열할 때

  • 처음: 물 (액체)
  • 나중: 물 (액체 상태 그대로)
  • 온도만 10℃ 상승

이때 물에 가해준 열이 바로 현열입니다. 현열 계산에는 앞에서 배운 Q = mcΔt 공식이 사용됩니다.

왜 '현열'이라고 부르나요?

한자로 풀이하면 현(顯: 나타날 현) + 열(熱: 열) 입니다.

즉, 열을 가했을 때 온도계에 20℃ → 25℃ → 30℃ 처럼 눈에 보이는 온도 변화가 나타나는 열이라고 생각하면 이해하기 쉽습니다.

2 공조냉동에서의 현열 예시
① 물을 가열할 때

20℃ 물 → 50℃ 물
온도가 올라가므로 현열입니다.

② 물을 냉각할 때

30℃ 물 → 10℃ 물
온도가 내려가더라도 상태 변화가 없으면 냉각 역시 현열입니다.

③ 공기를 냉각할 때

30℃ 공기 → 20℃ 공기
온도를 낮춘 부분은 현열입니다. (단, 습기가 물로 변하면 그 부분은 잠열!)

3 현열과 잠열의 비교

현열의 반대 개념은 잠열(숨은 열)입니다. 잠열 공식은 Q = mL (질량 × 고유잠열)을 사용합니다.

현열과 잠열이 함께 발생하는 경우 (물의 가열)
  1. 20℃ → 100℃ 물: 온도만 올라갑니다. 현열
  2. 100℃ 물 → 수증기: 온도는 100℃ 그대로인데 상태가 변합니다. 잠열
  3. 수증기를 더 가열 (100℃ → 120℃): 다시 온도만 변합니다. 현열
한 줄 요약: 온도가 변하면 현열, 상태가 변하면 잠열입니다!
4 기사 실기 현열 계산법

예제: 20℃ 물 1,000kg을 50℃까지 가열하는 데 필요한 열량은?

  • 질량 (m) = 1,000 kg
  • 물의 비열 (c) = 1 kcal/kg·℃
  • 온도차 (Δt) = 50 - 20 = 30℃

Q = mcΔt = 30,000 kcal
